# Proyectos

Proyectos de la materia. Cada uno es una aplicación Flask independiente.

| # | Proyecto | Descripción |
|---|---|---|
| 1 | [Árbol de expresiones](Proyecto_1_Arbol_Expresiones/) | Convierte expresiones infijas a posfijas, construye el árbol y lo evalúa |
| 2 | [Tres en raya ML](Proyecto_2_Tres_En_Raya_ML/) | Juego con IA Minimax y una IA entrenada con Machine Learning |

El proyecto 1 aplica la construcción de árboles y los recorridos. El proyecto 2
aplica la búsqueda en árboles y el entrenamiento de un árbol de decisión.
